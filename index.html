Git Mastery Cheat Sheet

Essential Commands for Professional Workflows

1. Repository Setup & Configuration

git initInitializes a new local Git repository in the current folder.
git remote add origin [URL]Links your local repository to a remote server (GitHub).
git remote -vVerifies the connection to the remote repository.
git branch -M mainRenames the default branch to 'main'.

2. Staging & Committing

git statusShows the state of the working directory and staged files.
git add .Adds all modified and new files to the staging area.
git commit -m "[message]"Saves the staged snapshot with a descriptive message.

3. Branching & Merging

git branchLists all local branches in the repository.
git checkout -b [name]Creates a new branch and switches to it immediately.
git checkout [name]Switches back to an existing branch (e.g., main).
git merge [name]Integrates changes from the specified branch into the current one.

4. Remote Operations & Syncing

git push -u origin mainUploads local commits to GitHub for the first time.
git pushUploads subsequent commits to the remote repository.
git pullFetches and integrates changes from the remote repo to local.
