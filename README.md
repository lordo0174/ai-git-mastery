# AI-Assisted Expense Tracker (Java)

## 📝 Overview
This is a professional Java-based command-line application designed to manage personal finances. It was developed as part of the **AI-Assisted Development and Git Mastery** assignment to demonstrate the synergy between Generative AI collaboration and professional version control management.

## 🎯 Purpose
The main goal of this application is to provide a simple yet effective way to:
- **Track Expenses:** Log daily expenditures with clear descriptions.
- **Financial Control:** List all recorded costs to monitor spending habits.
- **Data Insights:** Calculate the total amount spent (feature added via branching).
- **Workflow Mastery:** Show proficiency in Git CLI operations, branching strategies, and remote repository management.

## 🛠 Tech Stack
- **Language:** Java (JDK 17+)
- **IDE:** Visual Studio Code / IntelliJ IDEA
- **AI Tool:** Google Gemini (used for logic drafting and feature debugging)
- **Version Control:** Git (Command Line Interface)

## 💻 Git Commands Used
The following professional workflow was executed through the terminal:

### Repository Initialization
- `git init`: Initialized the local repository.
- `git remote add origin https://github.com/lordo0174/ai-git-mastery.git`: Linked the local project to GitHub.
- `git branch -M main`: Set the default branch name.

### Versioning & Commits
- `git status`: Checked the state of the working directory.
- `git add .`: Staged all changes for the next commit.
- `git commit -m "msg"`: Recorded snapshots of the development progress.

### Branching & Feature Management
- `git checkout -b feature-update`: Created a dedicated branch to develop the "Total Calculation" feature.
- `git merge feature-update`: Successfully integrated the new feature into the stable `main` branch.
- `git push -u origin main`: Uploaded the final history and code to the remote server.
